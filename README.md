# Xinyu Xiao · Academic homepage

[English](https://alex4210987.github.io/) · [中文](https://alex4210987.github.io/zh.html)

A static bilingual academic website, with the sidebar layout and blue-gray styling adapted from [Rui Yang’s homepage](https://yangrui2015.github.io/) and AcademicPages. Theme license: `LICENSE.theme`. Personal text, photos, CVs, and research documents are not covered by the theme license.

## Preview

Run `python3 -m http.server 8000` in this directory, then visit http://localhost:8000.

## Update

- Edit `index.html` (English) and `zh.html` (Chinese) together.
- `style.css` controls the responsive layout; `script.js` opens photos in an accessible dialog. Content and language links work without JavaScript.
- The two CV downloads in `assets/` are the author-supplied English and Chinese PDFs.
- `assets/Xinyu-Xiao-Bachelor-Thesis.pdf` is the public thesis edition, retaining original PDF pages 3–73 (71 pages). The cover, declaration/signature page, and acknowledgments are excluded. The original thesis is not included in the repository.
- `life.html` redirects to the homepage’s Hobbies section. `cv.html` and `cv-zh.html` provide English and Chinese interfaces. Each displays English and Chinese PDF readers side by side, with open and download links; mobile screens stack the readers.
- GitHub Pages publishes from the root of `main`.

No external font requests, analytics, or tracking scripts are used. Images are locally hosted; personal photo metadata has been removed. Preserve the generic description of the ongoing agentic kernel system and its “Under review” status; do not expose its project name or submission venue.
